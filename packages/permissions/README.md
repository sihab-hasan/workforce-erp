# @workforce-erp/permissions

Shared permission helpers and guard components for Workforce ERP apps.

## Current exports

- `buildPermissionCheck`
- `canAccess`
- `defaultPermissionMap`
- `Can`
- `RequirePermission`
- `usePermission`
- `PermissionCheck`
- `PermissionMap`

## Purpose

Use this package to centralize permission evaluation and UI-level permission guards across frontend apps in the monorepo.
